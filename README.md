# Minecraft Bedrock Animal Catalog Mod

Fauna Viva Bedrock is a Minecraft Bedrock mod, behavior pack, and resource pack for a curated animal catalog. It adds an Animal Egg Box item and 19 custom animal eggs, each labeled with a common name and scientific name, for use in Minecraft Bedrock and compatible Crafting and Building import workflows.

## Install

1. Use Minecraft Bedrock 1.21.50 or later.
2. Import or copy `resource_packs/AnimalWorld_RP` as a resource pack.
3. Import or copy `behavior_packs/AnimalWorld_BP` as a behavior pack.
4. Create or open a world.
5. Activate both packs in the world settings:
   - Settings → Resource Packs
   - Settings → Behavior Packs
6. Enable cheats if you want to use the included functions.
7. For packaged imports, zip the contents of each pack folder separately and rename the files with the `.mcpack` extension.
8. Import the resource pack first, then the behavior pack.
9. If your version of Crafting and Building supports add-on or `.mcpack` imports, use its import screen and activate both packs in the created world.

## Use

1. Run `/function give_egg_box` to receive the Animal Egg Box item.
2. Run `/function give_all_eggs` to receive one of every included animal egg.
3. Run `/function catalog` to display the catalog names and scientific names in chat.
4. Place an animal egg to spawn its corresponding vanilla Minecraft entity.
5. Use the vanilla entity's normal behavior and abilities after spawning.

- Frog — Rana temporaria
- Goat — Capra hircus
- Horse — Equus ferus caballus
- Llama — Lama glama
- Panda — Ailuropoda melanoleuca
- African Grey Parrot — Psittacus erithacus
- Pig — Sus scrofa domesticus
- Rabbit — Oryctolagus cuniculus

- Green Sea Turtle — Chelonia mydas
- Wolf — Canis lupus

Direct commands include `/give @s animalworld:egg_box` and `/give @s animalworld:egg_<animal>`. The project is a curated catalog of 19 Minecraft-compatible animals; it does not contain 77–88 million animal species. Animals without a matching vanilla Bedrock entity are not included.
